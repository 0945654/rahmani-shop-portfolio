نمای کلی پروژههدف، دامنه و محدودیت‌ها

هدف

فروشگاهی محلی برای لوازم جانبی کامپیوتر با تجربهٔ کاربری هم‌ردهٔ فروشگاه‌های بزرگ: جستجوی زنده، فیلترهای چندبُعدی، منوی دسته‌ها، صفحهٔ محصول کامل و نسخهٔ موبایل مستقل — همه با کد اختصاصی داخل قالب.

دامنه و محدودیت‌ها

قالب از سلسله‌مراتب قالب وردپرس ساخته شد: header، footer، front-page، قالب‌های ووکامرس، سایدبار فیلتر و صفحات خطا. محدودیت سخت: بدون صفحه‌ساز و بدون افزونهٔ پولی؛ هر قابلیت یا با کد قالب یا با API خود ووکامرس پیاده شد.

ویژگی‌های پیاده‌سازی‌شدهشش ستون اصلی محصول

قالب اختصاصی از صفر

header با جستجوی سراسری و منوی کشویی دسکتاپ، front-page بخش‌بندی‌شده، فوتر چهارستونه و قالب‌های اختصاصی ووکامرس بر پایهٔ template hierarchy.

فیلترهای سمت سرور

فیلتر برند/ویژگی، قیمت، دسته و موجودی با query-var های استاندارد ووکامرس؛ چیپ‌های فیلتر فعال با حذف تکی و «پاک کردن همه» — بدون وابستگی به جاوااسکریپت.

جستجوی زندهٔ محصولات

اندپوینت admin-ajax با wc_search_products و دراپ‌داون پیشنهاد شامل بندانگشتی، نام و قیمت؛ با گارد JSON تا پاسخ‌های غیرمنتظره هرگز رندر نشوند.

تجربهٔ موبایل مستقل

کشوی همبرگری با زیرمنوی دسته‌ها، شیت فیلترها از پایین صفحه، گرید دوستونه و اهداف لمسی بزرگ — بدون کتابخانهٔ خارجی.

صفحات تجاری کامل

محصول تکی با گالری چسبان، تب‌ها و محصولات مرتبط؛ سبد، تسویه‌حساب و تأیید سفارش با استایل معنایی؛ صفحهٔ ۴۰۴ اختصاصی با جستجو و دسته‌ها.

معماری CSS پایدار

لایه‌های base / fixes / mobile / commerce / polish با enqueue نسخه‌دار برای شکستن کش؛ استراتژی «جایگزینی کامل فایل» به‌جای الحاق‌های شکننده.

منوی بی‌اثر در ویرایشگر فهرست

تغییرات منو روی هدر اعمال نمی‌شد؛ هدر لینک‌های ثابت نشان می‌داد. علت، فعال‌بودن fallback_cb در wp_nav_menu بود که به‌جای منوی واقعی، لینک‌های سخت‌کد چاپ می‌کرد. با اختصاص فهرست واقعی به مکان primary، هدر کاملاً داده‌محور شد.

حالت «به‌زودی» و ربودن AJAX

پیشنهاد جستجوی زنده به‌جای JSON، صفحهٔ کامل «اتفاقات بزرگی در راه است» را داخل دراپ‌داون می‌ریخت. حالت Coming Soon ووکامرس پاسخ admin-ajax را برای کاربر مهمان بازنویسی می‌کرد. فروشگاه روی Live قرار گرفت و لایهٔ catch به fetch اضافه شد.

آبشار CSS و فایل‌های شکسته

قوانین جدید «اعمال نمی‌شدند»؛ یک آکولاد بستهٔ جامانده همهٔ قواعد بعد از خود را مرده می‌کرد و enqueue بدون نسخه، کش قدیمی می‌داد. با لایهٔ fixes مجزا، شماره‌نسخه‌دارکردن enqueue و استراتژی جایگزینی کامل فایل، پایداری بازگشت.
